# 哈希值对比工具

一个仅使用 Python 标准库编写的桌面工具，可比较两个文件或两个文件夹的内容是否完全一致。

## 功能

- 支持普通本地路径、Windows 映射网络驱动器和 SMB/UNC 路径（如 `\\NAS\\共享\\资料`）
- 支持 SHA-256、SHA-512、SHA-1、MD5，默认使用 SHA-256
- 文件夹递归比较相对路径、空文件夹、文件大小与文件内容哈希
- 显示总体哈希、处理进度和逐项差异
- 支持取消长时间任务和导出 UTF-8 CSV 报告
- 后台计算，扫描 NAS 大文件时 UI 不会卡死

## 运行

需要 Python 3.10 或更高版本（安装时需包含 Tkinter，Windows 官方 Python 通常默认包含）。

最简单的方式是双击 `启动哈希对比工具.bat`，启动脚本会自动查找当前用户安装的 Python。

也可以在已配置 Python 的终端中运行：

```powershell
python app.py
```

## NAS 使用说明

可以通过“选文件/选文件夹”选择已映射的网络驱动器，也可以在输入框直接粘贴 UNC 路径。工具使用 Windows 当前登录会话访问共享目录；如果尚未登录 NAS，请先在资源管理器中连接共享并保存凭据。

“内容完全一致”表示内容和目录结构一致，不比较修改时间、创建时间、ACL 权限、文件所有者或 NTFS 扩展属性。目录中的符号链接按链接目标文本比较，不跟随链接，以避免循环路径。
